# Netflix Movies and TV Shows Data Analysis

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset to understand content trends, genre distribution, and production patterns. The analysis is done using Python with libraries such as Pandas, Matplotlib, and Seaborn.

## Project Overview

The goal of this project is to analyze Netflix's content library and identify patterns related to movies, TV shows, genres, countries, and release trends. By analyzing the dataset, we can understand how Netflix content has evolved over time.

## Dataset

The dataset used in this project contains information about Netflix movies and TV shows, including:

- Title
- Type (Movie or TV Show)
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genre
- Description

Dataset source: Netflix Movies and TV Shows dataset.

## Tools and Libraries Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Analysis Performed

The following analyses were conducted:

- Distribution of Movies vs TV Shows
- Top content producing countries
- Content release trend over the years
- Most common genres on Netflix
- Rating distribution of Netflix content

## Visualizations

The project includes several visualizations to better understand the data:

- Pie Chart – Distribution of Movies vs TV Shows
- Bar Chart – Top Countries Producing Netflix Content
- Bar Chart – Most Common Genres
- Line Chart – Content Release Trend Over Years
- Rating Distribution Chart

## Key Insights

- Netflix contains significantly more **Movies than TV Shows**.
- The **United States produces the highest number of titles**.
- Netflix content production increased rapidly after **2015**.
- Drama and international genres are among the most common categories.

## Conclusion

This analysis helps in understanding how Netflix's content library is structured and how it has grown over time. The insights can help media companies and analysts understand global streaming trends.
